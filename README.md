# PPAI - Santé et Sécurité Québec

Application de génération intelligente de programmes de prévention SST avec intégration du registre des risques, conforme aux exigences CNESST/LMRSST.

## 🚀 Fonctionnalités principales

- **Génération de programmes SST** - Création automatisée de programmes de prévention conformes aux exigences CNESST
- **Registre des risques dynamique** - Évaluation et priorisation des risques avec matrice 5x5 interactive
- **Analyse prédictive** - Anticipation des risques potentiels via intelligence artificielle
- **KPI par rôle** - Suivi des indicateurs de performance adaptés à chaque niveau de responsabilité

## 🛠️ Architecture technique

- **Frontend**: React 18 avec TypeScript
- **UI**: Tailwind CSS + shadcn/ui
- **Backend**: Supabase (PostgreSQL, Edge Functions)
- **IA**: Intégration Claude 3.5 Sonnet
